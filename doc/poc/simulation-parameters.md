## 1. 目的

本資料は、基本設計書のレース進行モデルへ渡す指標と係数を、データ分析で作成する単位で整理したものである。実装は含まない。分析結果は、馬ごとの表と共有係数の表に分けて出力する。

各指標は担当する観測を一つに固定する。

| 観測 | 担当する指標 |
|------|----------------|
| 走破タイムの水準 | 基準時計 `parTime` |
| 上がり3F | 最高速 `speed` |
| 距離が延びたときの追加タイム | スタミナ `stamina` |
| 第1コーナーの位置 | 出足 `acceleration` |

作成は2段で行う。

1. 個体指標を 0–100 で作る
2. 個体指標を同時回帰へ入れ、速度倍率へ変換する

斤量・枠番・馬番は出走表の実測であり、本資料の推定対象に含めない。

## 2. 共通記号

| 記号 | 意味 |
|------|------|
| `t` | 完走タイム（秒）。競走中止・失格・降着は除外する |
| `t_3F` | 上がり3F（秒） |
| `d` | 距離（m） |
| `n` | 出走頭数 |
| `pos` | 通過順 |
| `q` | 通過位置。`q = (pos - 1) / (n - 1)`。0 が先頭、1 が最後方 |
| `SF` | 速度指数。`SF = (parTime - t) / parTime`。基準より速いと正 |
| `z` | 標準化した指標。`z = (指標 - 50) / 10` |
| `w` | 斤量（kg） |

馬ごとの平均は、出走数が少ない馬を全体平均へ縮約する。

```
mu_hat = (n / (n + k)) * x_bar + (k / (n + k)) * m
k = within_variance / between_variance
```

`m` は全体平均、`x_bar` はその馬の平均である。

着差は馬身へ数値化し、1馬身 = 2.4 m でメートルへ換算する。ハナ・アタマ・クビは、採用するデータ源の換算表で固定する。

## 3. 馬・騎手の指標

| パラメータ名 | 意味 | 推定に使う観測データ | 計算式または推定方法 |
|---|---|---|---|
| `speed` | 最高速の相対点（0–100） | 上がり3F、馬場、距離、馬場状態、ペース区分 | `v_3F = 600 / t_3F`。同一条件の平均を引いた残差を馬ごとに縮約し、全体で平均 50・標準偏差 10 へ写す。`speed_i = 50 + 10 * z_hat_i`。0 と 100 で打ち切る |
| `stamina` | 距離が延びてもタイムが崩れない度合い | 走破タイム、距離、基準時計 | 同一馬で `t - parTime = a_i + alpha_i * max(d - 1600, 0) / 200 + e`。`alpha` が小さい馬ほど持続力が高い。`stamina_i = 50 - 10 * z(alpha_i)` |
| `acceleration` | 出足の良さ | 第1コーナー通過順（無ければ最初の通過地点）、頭数 | `q` の馬平均を縮約する。`acceleration_i = 100 * (1 - q_hat_i)` |
| `cornering` | コーナーが連続するコースでの速度維持 | 競馬場別の `SF` | 高曲率（函館・福島・小倉・中山）と低曲率（東京・新潟・京都）で、同一馬の `SF` 差を縮約する。`cornering_i = 50 + 10 * z(SF_高 - SF_低)` |
| `runningStyle` | 脚質。`front` / `stalk` / `mid` / `closer` | 第1コーナー通過順、頭数、直近走 | 直近5走の `q` を縮約した `q_hat` で分類する。0.15 以下が `front`、0.40 以下が `stalk`、0.70 以下が `mid`、それ以外が `closer` |
| `surfaceAptitude.turf` / `surfaceAptitude.dirt` | 芝・ダートそれぞれの適性（0–100） | 馬場種別ごとの `SF` | 馬場ごとに馬平均 `SF` を縮約し、50 + 10z へ写す。出走が無い側は 50 |
| `distanceOpt` | その馬の適性距離（m） | 距離ごとの `SF` | `SF = c0 + c1 * d + c2 * d^2` を馬ごとに当て、`c2 < 0` のとき `distanceOpt = -c1 / (2 * c2)`。走数が足りない馬は、平均 `SF` が最大の距離帯の中央値 |
| `jockeySkill` | 騎手の力量（0–100） | `SF`、馬、騎手 | `SF = horse_i + jockey_j + e` の混合モデル。騎手効果を平均 50・標準偏差 10 へ写す |

---

## 4. 指標を速度へ換算する係数

完走馬について、次の同時回帰の係数をシミュレータの換算係数とする。

```
SF = βv * z_speed
   + βs * z_stamina * max(d - 1600, 0) / 200
   + βw * (w - w_ref) * d / 1000
   + βj * z_jockey
   + βd * ((d - distanceOpt) / 1000)^2
   + e
```

| パラメータ名 | 意味 | 推定に使う観測データ | 計算式または推定方法 |
|---|---|---|---|
| `speedScale` | 最高速が1標準偏差高いときの速度倍率 | 同時回帰 | 回帰係数 `βv`。当日速度は基準速度の `(1 + βv * z_speed)` 倍 |
| `weightRef` | 斤量補正の基準（kg） | 斤量 | 推定対象の斤量中央値 |
| `weightPerKg` | 1 kg・1 km あたりのタイム増（秒） | 斤量、距離、走破タイム | `weightPerKg = -βw * parTime` |
| `jockeySpan` | 騎手力が1標準偏差高いときの速度倍率 | 騎手効果、走破タイム | 回帰係数 `βj` |
| `distanceSigma` | 適性距離から外れたときの落ち幅（m） | 距離、`SF`、`distanceOpt` | `distanceSigma = 1000 * sqrt(-1 / (2 * βd))`。適性倍率は `exp(-0.5 * ((d - distanceOpt) / distanceSigma)^2)` |

## 5. 基準時計と馬場

| パラメータ名 | 意味 | 推定に使う観測データ | 計算式または推定方法 |
|---|---|---|---|
| `parTime[course,surface,distance,going]` | その条件の代表走破タイム（秒） | 完走タイム、競馬場、芝ダート、距離、馬場状態 | セルごとに完走タイムの中央値。走数が 30 未満のセルは `log(t) = a[course,surface] + b * log(d) + c[going]` の予測値で補完する |
| `timeSigma[surface,distance]` | 走破タイムのばらつき（秒） | 完走タイム、`parTime` | `1.4826 * MAD(t - parTime)`。競馬場はプールし、芝ダート × 距離で求める |
| `trackFactor[surface,going]` | 馬場状態の速度倍率。良は 1 | 同一競馬場・同一距離の完走タイム、馬場状態 | `timeRatio = median(t \| going) / median(t \| 良)`。速度倍率は `1 / timeRatio`。走数 `n` が少ないセルは `(n * ratio + 20 * 1) / (n + 20)` で良へ縮約する |
| `earlyPar[course,distance]` | 先頭の前半 600 m の基準タイム（秒） | 先頭馬の通過タイム、または前半ラップ | 先頭の 600 m タイムの中央値。記録が半里程だけのコースは、距離比で 600 m に比例換算する |

## 6. ペース・脚質・位置取り

ペース区分は `ratio = t_early / earlyPar` で付ける。小さいほど前半が速い。

| パラメータ名 | 意味 | 推定に使う観測データ | 計算式または推定方法 |
|---|---|---|---|
| `highPaceRatio` | ハイペースと判定する上限 | 前半 600 m タイム、`earlyPar` | `ratio` の 25 パーセンタイル |
| `slowPaceRatio` | スローペースと判定する下限 | 前半 600 m タイム、`earlyPar` | `ratio` の 75 パーセンタイル。間はミドルペース |
| `stylePace[style,pace]` | 脚質とペースの相性（速度倍率） | 脚質、ペース区分、`SF` | 脚質内の全体平均 `SF` を引く。`stylePace = 1 + mean(SF \| style, pace) - mean(SF \| style)` |
| `moveDistance[style]` | 仕掛けを始める残り距離（m） | 200 m ラップ、脚質、通過順 | その脚質の速度がレース平均速度を上回り始める残り距離の中央値 |
| `kick[style]` | 仕掛け区間の速度上乗せ（倍率） | 最終 200 m のラップ、中盤ラップ、脚質 | `v_last / v_mid` の脚質別中央値。スタミナ項で説明できる減速を除いた比を使う |
| `startPosition[style]` | 脚質ごとの初期位置（0 が先頭） | 第1コーナー通過順、頭数、脚質 | `mean(q \| style)` |
| `accCoef` | 出足が初期位置を前へ進める量 | 第1コーナーの `q`、`acceleration`、脚質 | `q = startPosition[style] + accCoef * z_acceleration + gateCoef * (gate - gate_bar) + e` の回帰係数 |
| `gateCoef[course,distance]` | 枠が初期位置へ与える補正 | 枠番、第1コーナー通過順、競馬場、距離 | 同じ回帰の `gateCoef`。コース × 距離ごとに推定し、走数が少ないセルは全コースの係数へ縮約する |
| `startDelaySigma` | 出遅れのばらつき（秒） | 出遅れの記載、第1区間タイム | 出遅れ馬の第1区間残差の標準偏差 |
| `blockGap` | 前が詰まると減速が始まる車間（m） | 前が壁になった記載、直線の順位固定、上がり3F | 順位が直線まで動かず、上がりが同一脚質の平均より遅い馬の割合を作る。シミュレーションの発生率がその割合と一致するまで車間を合わせる。下限は 1 馬身の 2.4 m |
| `blockSpeedRatio` | 詰まった馬の速度／直前の馬の速度 | 前が壁の馬と、その直前の馬の上がり3F | 両者の `v_3F` の比の中央値 |

## 7. コース形状

| パラメータ名 | 意味 | 推定に使う観測データ | 計算式または推定方法 |
|---|---|---|---|
| `sectionLength[course,distance][]` | スタート、各コーナー、向正面、直線の長さ（m） | コース図、ハロン棒の位置 | 図面の区間長をそのまま読む |
| `cornerAngle[course,corner]` | 各コーナーの旋回角（rad） | コース図 | 図面の中心角をラジアンで読む |
| `laneWidth[course,distance]` | 1頭分の内外幅（m） | コース幅、コーナー区間の内外のタイム差 | 初期値はコース幅 ÷ 並走頭数。外を回した距離は `(lane - 1) * laneWidth * cornerAngle`。この距離ロスが、コーナー区間の内外タイム差 × 速度と一致するよう `laneWidth` を回帰する |

## 8. 試行ごとのばらつき

| パラメータ名 | 意味 | 推定に使う観測データ | 計算式または推定方法 |
|---|---|---|---|
| `sigmaSpeed` | 同一条件でも試行ごとに速度が揺れる対数標準偏差 | 斤量・馬場・騎手を除いた同一馬のタイム | `e = log(t) - log(t_hat)` の標準偏差。`t_hat` は同時回帰の予測タイム |
| `sigmaSection` | 区間速度の対数標準偏差 | 200 m ラップ | 馬とレースの効果を除いたラップ残差 `log(lap) - log(lap_hat)` の標準偏差 |
| `troubleRate` | 接触や進路妨害で速度を落とす確率 | 競走中止、降着、不利の明記 | 該当のある出走数 ÷ 全出走数。中止・降着と、走行を続けた不利は別定数にする |

設計で確定している値は推定しない。時間刻みは 0.1 秒（または 200 m 区間）、Monte Carlo は 1,000 回、各試行の乱数種は `baseSeed + trialIndex` である。

## 9. レースごとに組み立てる予想入力

出走表が決まったあと、共有係数と個体指標から当日の入力を作る。

| パラメータ名 | 意味 | 推定に使う観測データ | 計算式または推定方法 |
|---|---|---|---|
| `vMax[horse]` | その日の最高速（m/s） | 距離、馬場、馬場状態、斤量、騎手、個体指標、基準時計 | `v = (d / parTime) * (1 + βv * z_speed) * trackFactor * distFactor * (1 + βj * z_jockey)`。斤量は `v` を `parTime / (parTime + weightPerKg * Δw * d / 1000)` 倍する。`distFactor = exp(-0.5 * ((d - distanceOpt) / distanceSigma)^2)` |
| `pacePrior` | ハイ・ミドル・スローの確率 | 出走馬の脚質と `speed`、距離、競馬場 | 多項ロジスティック回帰。説明変数は `front` と `stalk` の頭数、その平均 `speed`、距離、競馬場。結果が3区分の確率 |
| `initialQueue[horse]` | スタート直後の前後位置 | 脚質、出足、枠番 | `q = startPosition[style] + accCoef * z_acceleration + gateCoef * (gate - gate_bar)`。0–1 へ収める |
| `initialLane[horse]` | スタート直後の内外 | 枠番、`laneWidth` | 枠番を外へ数えたレーン番号。同脚質が重なるときは内側の枠から順に内レーンを割り当てる |

`stylePace`、`cornering`、`kick`、スタミナ消費はレース進行中に掛ける係数であり、`vMax` には畳み込まない。

## 10. 係数を採択するときに合わせる実績

これらはシミュレータへ渡す入力ではなく、推定した係数の採否を決める集計である。

| パラメータ名 | 意味 | 推定に使う観測データ | 計算式または推定方法 |
|---|---|---|---|
| `favoriteWinRate` | 1番人気の勝率 | 人気、着順 | 1番人気の勝利数 ÷ 1番人気がいるレース数。設計の目安は約 30%。`sigmaSpeed` をこの値へ合わせる |
| `styleWinRate[style]` | 脚質別の出走あたり勝率 | 脚質、着順 | その脚質の勝利数 ÷ その脚質の出走数 |
| `gateWinRate[course,distance,gate]` | 枠別の勝率 | 枠番、着順、競馬場、距離 | 枠ごとの勝利数 ÷ 出走数。頭数帯ごとに分ける |
| `showRate[popularity]` | 人気ごとの3着内率 | 人気、着順 | その人気の3着以内の数 ÷ 出走数 |
| `marginQuantile[surface,distance]` | 着差分布 | 2着以下の着差 | 1馬身換算後のメートル着差について、50・75・90 パーセンタイルを求める |
