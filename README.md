# KEIBA_RACING_SIMULATOR

競馬レースのシミュレータ。プロトタイプは、1 レースの展開をブラウザのコース上に描画する。

React アプリのコードと設定は [`keiba-racing-simulator`](./keiba-racing-simulator) にある。

```bash
cd keiba-racing-simulator
npm install
npm run dev
```

`npm test` でシミュレーションのテストを実行する。
